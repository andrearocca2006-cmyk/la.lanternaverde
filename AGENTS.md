# Continuità — La Lanterna Verde

Repository principale: https://github.com/andrearocca2006-cmyk/la.lanternaverde.git

Prima di ogni modifica: git fetch origin; controllare branch, stato, log e differenze. Integrare con fast-forward solo su working tree pulito. Mai force-push, sovrascritture o ripartenza da template. Se il remoto è inaccessibile, dichiararlo e non assumere che lo stato locale sia aggiornato.

Leggere README.md, docs/RECOVERY.md e docs/REQUIREMENTS.md. Preservare prenotazioni persistenti, capienza atomica, token riservati, autorizzazione server, adulti/bambini, gruppi, calendario e accessibilità. Niente localStorage come database o GitHub Pages come backend.

Bozza privata e noindex; non cambiare audience o dominio senza richiesta. Non committare credenziali, database, dati dei clienti o esportazione grezza della conversazione. I test storici dichiarati non equivalgono a prove della ricostruzione. Non inventare foto autentiche, recensioni, prezzi o dati legali.

Concludere con build e prove mirate, commit e push autorizzati senza riscrivere storia; verificare hash remoto. Documentare ogni limitazione.
